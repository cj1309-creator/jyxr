# Taste
- Communicates in Chinese (Simplified); expects explanations and answers in Chinese. Confidence: 0.8
- Explores unfamiliar code by asking "how does X reach Y" / "how does execution reach this method" / "where does this parameter come from" style questions and expects a full call-chain trace from the entry point (or data origin) to the target, with concrete `file:line` references for each hop, covering every branching path (e.g. both the UI-driven and the AI/automated path). Confidence: 0.75
- When a step in a traced chain is unclear, expects the underlying mechanism to be explained (e.g. reflection/attribute-based dispatch), not just the high-level path. Confidence: 0.5
- Follows up a call-chain trace with runtime/execution-semantics questions (e.g. "there are 4 `EnterAsync`s, do they run simultaneously?", or "there are so many `new WaitingTimelineState()` yet the event only fires once per turn — why?") and expects the actual execution model explained — nested vs parallel awaits, what serializes the entry points (e.g. a `SemaphoreSlim` intent gate), and especially the distinction between constructing an object and actually entering it (`new X(...)` vs `TransitionAsync(new X(...))`), which assumptions are conventions rather than enforced — plus common misconceptions, not a bare yes/no. Confidence: 0.55
- Frequently sends a bare code snippet (method body, type/data definition, or an entire class file) with no accompanying question, expecting it to be explained section-by-section (purpose of each member/step, why each guard/attribute/check exists). He means *explain*, not *act*: when the agent instead pivots to proposing code changes or asks "which approach (A) or (B) do you prefer", he corrects with "我是想让你解释一下" — so default to narrating what the code does before suggesting any modification. Confidence: 0.9
- Asks capability/"how do I do X" questions (e.g. how to inspect a variable's value, whether something like `printf` exists) and expects a verified inventory of what the codebase already offers, an explicit statement when nothing exists, and for missing features a concrete minimal implementation sketch; answers must be practical and grounded in actual code rather than generic advice. Confidence: 0.55
- Asks "what is this type/object for" (作用) questions about a specific type and expects its architectural role: which layer owns it, who creates/consumes it, what it is NOT (e.g. how it differs from a similarly named event bus or a private control-flow type), and the design rationale. Confidence: 0.6
- The "作用" questions are not limited to project-defined types; they also target framework/language-level concepts (e.g. `CancellationToken`), and expect both the general mechanism explained and the project's concrete usage pattern (who produces, who passes, who consumes it, plus gotchas). Confidence: 0.65
- Pastes a raw error with no explicit question — whether a compiler error (e.g. "'X' does not contain a definition for 'Y'") or a runtime exception/stack trace (e.g. a Godot `ContentLoadException` crash at startup) — expecting the root cause located, explained, fixed in place, and the fix verified by building the affected project. Confidence: 0.65
